# PrimeNumbers

Prime number generators in various programming languages.

## Running Software

First, clone this repository.
```
git clone https://github.com/caleb-james-smith/PrimeNumbers.git
```

### Web App

The web app code is stored in the directory `web_app`.
The web app uses ES modules, which browsers load over HTTP (not directly from a file).
Start a static server and specify a port number (for example, port `8000`).
```
cd web_app
npx serve -l 8000
```
Then, open the web page in a browser at http://localhost:8000/PrimeNumbers.
Enter a positive integer and click the `Run` button.
